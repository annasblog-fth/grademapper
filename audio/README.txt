Put real recordings here (optional). The sound player uses these files when they exist:

  rain.mp3    forest.mp3    ocean.mp3

If a file is missing, grademapper plays a sound made on the device instead, so nothing breaks.

Tips for good files
  - MP3, mono, about 64 kbps, 30 to 90 seconds. Small files load fast and work offline.
  - Make them loop smoothly: fade the end into the start (a 2 second crossfade) in a free editor such as Audacity.
  - Only use recordings you are allowed to use (your own, public domain / CC0, or a licence that allows it).
    Write each one in CREDITS.txt (title, author, source link, licence).
